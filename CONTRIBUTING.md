# Як робити внесок

## Hard rules

- Усі зміни — тільки через Pull Request, ніколи напряму в `main`.
- Ніколи не додавати паролі, API-ключі, токени доступу в жодному файлі.
- Ніколи не додавати персональні чи фінансові дані клієнтів.
- Дуже чутливі внутрішні дані (наприклад, зарплати) — тримати поза цим репозиторієм.
- Особисті нотатки й рефлексії конкретної людини сюди не йдуть — це не про командний мозок.
- Якщо зміна додає, перейменовує або видаляє документ, у тому самому PR онови таблицю 'Start here' у README.md, щоб вона вказувала лише на файли, які існують.
