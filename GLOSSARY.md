# Glossary

> **Owner:** Oleksandra Riabtseva · **Backup:** unassigned · **Last reviewed:** 2026-11-08

This page explains the terms and abbreviations the Fernway team uses that can't be found on the internet.

- **Account vs venue** — one account can have many venues: billing is per venue, contracts are per account. New hires mix these up constantly. See [docs/about-company.md](docs/about-company.md).
- **Activation** — used by everyone, defined by nobody. Sales means the first published schedule, Lukas Weber means a full week scheduled, and the Metabase dashboard measures something else again (see [open-questions.md](open-questions.md)).
- **Friday freeze** — the no-deploys-on-Friday rule. See [docs/team-rules/friday.md](docs/team-rules/friday.md).
- **Ghost shift** — a published shift nobody claimed. The single most common support complaint; see [docs/runbooks/support-escalation.md](docs/runbooks/support-escalation.md).
- **Mara-check** — a pricing exception that needs the CEO (Mara Voss). See [docs/about-company.md](docs/about-company.md) and [docs/team.md](docs/team.md).
- **Pay rules** — the per-country break and overtime configuration set during customer onboarding. See [docs/runbooks/customer-onboarding.md](docs/runbooks/customer-onboarding.md).
- **T2L** (time to live) — from contract signed to first schedule published. Typically 1–3 days; Fernway's main onboarding metric, see [docs/about-company.md](docs/about-company.md).
- **The importer** — the CSV staff-import tool. See [docs/runbooks/customer-onboarding.md](docs/runbooks/customer-onboarding.md).
