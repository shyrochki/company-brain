# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Що це за репозиторій

Company Brain — єдине джерело правди компанії у форматі docs-as-code: Markdown у Git, рев'ю через Pull Request. Це база знань, а не кодова база, тому збірки, лінтера й тестів тут немає.

Інші інструменти (Slack, Notion, Drive, Gmail) живлять цей репозиторій, але саме він є джерелом правди. Якщо дані розходяться, правильним вважається записане тут; розбіжність варто показати людині, а не виправляти мовчки.

## Структура

- `docs/` — знання компанії за напрямами:
  - `company/` — місія, цінності, структура, як ми працюємо
  - `engineering/` — архітектура, технічні рішення, стандарти
  - `product/` — стратегія, користувачі, роадмап
  - `operations/` — внутрішні операційні процеси
  - `go-to-market/` — маркетинг, продажі, позиціонування
  - `people/` — найм, онбординг, командні практики
- `runbooks/` — покрокові процедури
- `agents/` — реєстр AI-агентів
- `templates/` — шаблони нових документів
- `meta/` — документи про сам Company Brain
- `scripts/`, `tools/` — обслуговування репозиторію
- `GLOSSARY.md` — терміни компанії
- `CONTRIBUTING.md` — повні правила внесення змін

## Правила

### Відповіді на запитання про компанію

Спершу шукай відповідь у `docs/` (а також у `runbooks/`, `agents/` і `GLOSSARY.md`, якщо це доречно), і лише потім відповідай. Не вигадуй: якщо відповіді немає, прямо скажи про це. Посилайся на файл, з якого взято відповідь.

### Зміни

Нова інформація потрапляє сюди тільки через Pull Request, ніколи напряму в `main`. Для кожної зміни створюй окрему гілку.

Якщо зміна додає, перейменовує або видаляє документ, у тому самому PR онови таблицю 'Start here' у README.md, щоб вона вказувала лише на файли, які існують.

### Що не можна додавати

У жодному файлі, прикладі чи повідомленні коміту не має бути:

- паролів, ключів доступу, API-ключів, токенів;
- персональних даних клієнтів;
- фінансових деталей;
- дуже чутливих внутрішніх даних (наприклад, зарплат);
- особистих нотаток і рефлексій конкретної людини.

Якщо такі дані трапилися у матеріалі, який треба додати, не переноси їх і повідом про це людину.
